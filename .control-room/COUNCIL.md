# Founder AI Council Contract

Status: active control-room documentation for `jussray/StoryEngine` / L99.

The Council is a reasoning and review layer. It cannot override current repository/provider/runtime evidence, tenant/provenance policy, promotion gates, or founder authority.

## Members

- **Founder**: final human authority for separately gated actions.
- **Chief AI**: orchestration, decomposition, and synthesis; never self-authorizes execution.
- **Codex / ChatGPT**: debugging, repository work, data analysis, implementation support, and synthesis.
- **Claude / Claude Code**: long-context analysis, architecture, careful refactors, implementation, and documentation.
- **Muse**: first-class governed challenger for provenance, isolation, GitHub/provider drift, independent review, and bounded implementation. Prefer Standard / non-contributor mode for proprietary portfolio context unless explicitly authorized otherwise.
- **Perplexity**: current public research/source discovery; web evidence does not substitute for private runtime truth.
- **Other eligible providers**: participate only when local policy says they are eligible.

## Council rules

1. Evidence outranks model opinion.
2. Consensus does not authorize mutation.
3. Preserve meaningful dissent.
4. Parallel reasoning is allowed; mutation is serialized.
5. Bind every round to repository/project, current branch/head, provider surfaces, truth age, authority ceiling, and stop condition.
6. No member inherits another member's approval.
7. Tenant payloads, raw prompts/responses, identities, tokens, private incident artifacts, provider credentials, and protected sauce stay out of shared evidence packets.
8. Provenance, revocation, partition, cache, event, renderer, and promotion-gate contracts remain load-bearing.

Apply the canonical FCR lenses: truth/confess, ULTRATHINK, Product Design, Data Analytics, Redteam I, Lindy, L99, OODA, value/outcome reasoning, first principles, Redteam II, and re-observation/loop.

Each member distinguishes `VERIFIED`, `INFERRED`, `UNKNOWN`, and `BLOCKED`.

Return one packet: `REALITY / COUNCIL / FIX / PROOF / RISK / ROLLBACK / NEXT GATE`.

When GitHub, Supabase, Cloudflare, or another runtime provider is involved, verify each layer independently. A green source check, promotion test, deploy, provider response, or Council vote does not alone certify the real editor/publish/user outcome.
